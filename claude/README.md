# Claude Code

My configuration files for [Claude Code](https://claude.com/product/claude-code).

## Installation

* Copy `scripts/claude-bwrap.sh` to a directory in `PATH` and ensure that you
  use it to run Claude Code (it is for running Claude Code inside the
  [bubblewrap](https://github.com/containers/bubblewrap) sandbox).
* Copy the `.claude` directory to `$HOME` (Claude's configuration file and
  `CLAUDE.md`).
* Copy the `.sage` directory to `$HOME` (configuration for
  [Sage](https://github.com/gendigitalinc/sage)).
* Copy the `.config/ccstatusline` directory to `$HOME/.config` (configuration
  for [ccstatusline](https://github.com/sirmalloc/ccstatusline)).
